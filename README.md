# ProBarbershop — For Example — For my Portfolio

**EXAMPLE Barber Atelier · Issue Nº 01** — a demo website of a fictional independent European barbershop.

**Live:** https://timur-alt2008.github.io/ProBarbershop-ForExample-For-my-Portfolio/

## Concept
The site is built like an issue of a men's magazine: a cover, a manifesto, a price list, profiles, a lookbook, a booking ticket and a colophon.

- Visual language: men's magazine × fashion × European barber culture × architecture studio
- Palette: paper, ink and bottle green; photography is always monochrome
- Type: Archivo (condensed / expanded), Instrument Serif, IBM Plex Mono

## What works
- Interactive price list with a floating photo preview
- Expanding barber panels — "Sit in …'s chair" pre-fills the booking
- Pinned horizontal lookbook with a lightbox (keyboard + swipe)
- "The space" window that opens while you scroll
- Booking ticket: service, barber, date, time slots by opening hours, validation, live summary (demo mode — nothing is sent)
- Live opening status and a weekly hours chart
- Fully responsive, respects reduced motion

## Tech
One self-contained `index.html` (HTML + CSS + vanilla JS), no build step.
